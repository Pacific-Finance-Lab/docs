---
title: "Parameters"
description: "Governance-set values every listing is checked against."
---

Governance sets these values. A listing proposal may specify per-token values within the bounds they set.

<Info>
  **Not yet set.** No value below has been set. Fourteen references across the docs point at this page.
</Info>

| Parameter | Governs | Value |
|---|---|---|
| `CR_min` | The minimum coverage ratio a listing must meet | Not yet set |
| Minimum lock period | The shortest cycle a listing may declare | Not yet set |
| Staking minimum | The floor on an issuer stake, and how it scales with declared budget | Not yet set |
| Liquidity placement template | The ranges within which opening liquidity may be placed | Not yet set |
| Grace period | How long after maturity before deprecation begins automatically | Not yet set |
| Holder exit window length | How long holders have to exchange against committed stablecoin | Not yet set |
| Timelock delay | How long a passed proposal is queued before execution | Not yet set |
| Swap protocol fee | Taken on volume in the Gateway pools | Not yet set |
| Inventory sale fee | Taken on stablecoin paid out to an issuer above its committed amount | Not yet set |
| Supported quote assets | Which stablecoins may be used as quote assets | Not yet set |
| Lock-up tiers and fee discounts | What locking PAFI returns | Not yet set |
| Vote reward sizing | What a voter records and what counts as completing without incident | Not yet set |
| Agent rule default caps | The amount, frequency, slippage, and validity ceilings a rule runs under | Not yet set |

See [Governance](/governance/overview) for how these are changed and when a change takes effect.
