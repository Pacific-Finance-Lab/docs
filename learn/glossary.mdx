---
title: "Glossary"
description: "Terms used throughout these docs."
---

| Term | Meaning |
|---|---|
| **PAFI Agent** | The interface that takes instructions in ordinary language and carries out actions on point tokens. Called the agent interface in the whitepaper |
| **Committed stablecoin** (`I`) | USD stablecoin an issuer deposits and commits for the duration of a cycle. The sole source of funds for a holder exit window |
| **Coverage** | The relation sizing committed stablecoin against the issuance budget at the initial reference price |
| **Cycle** | The period for which a set of declared terms governs a point token's market |
| **Deficit Reserve** | A portion of the Community and Ecosystem allocation held against deficits. Applied only by affirmative governance vote |
| **Deprecation** | The defined contract sequence a cycle enters at maturity where no approved renewal exists |
| **Gateway** | The permissionless, issuer-gated on-chain spot exchange in which point tokens are exchanged |
| **Grace period** | The interval after maturity before deprecation begins automatically |
| **Holder exit window** | The period during deprecation in which point tokens may be exchanged against committed stablecoin |
| **Initial reference price** (`P0`) | The opening price declared in a listing proposal. An opening parameter, not a floor |
| **Issuance budget** (`U + L`) | The limit outstanding supply cannot exceed |
| **Issuer inventory allocation** (`L`) | The portion of the issuance budget an issuer issues to itself and supplies to the pool as liquidity |
| **Issuer-gated** | A market opens only for an issuer whose listing governance approved |
| **Lock period** | The period for which committed stablecoin is locked by contract |
| **Point token** (PT) | A transferable on-chain representation of an issuer-defined point balance |
| **Redemption** | Burning a point token and crediting points in the issuer's ledger |
| **Redemption processing commitment** | The period within which an issuer undertakes to credit points for a redemption request |
| **Routing layer** | The layer connecting liquidity realized on the Gateway to integrated venues |
| **Slashing** | Reduction of an issuer stake on one of the two conditions enumerated in the contracts |
| **USD stablecoin** | A transferable digital asset designed to maintain a stable value of one United States dollar and redeemable by its issuer for that value |
| **User conversion allocation** (`U`) | The portion of the issuance budget available for conversion by holders |
